# Head Out | Discover Singapore Events

Your digital curator for the best experiences in the Lion City.

## About

Head Out cuts through the noise to bring you curated workshops, pop-ups, and mixers hidden in the heart of Singapore.

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Material Symbols
- Google Fonts

## Development

This is a static HTML site. Open `index.html` in your browser to view locally.

## Deployment

Deploy to any static hosting service (Vercel, Netlify, GitHub Pages, etc.)
